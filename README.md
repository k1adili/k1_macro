# ضبط‌کنندهٔ ماکرو برای ویندوز

برنامهٔ دسکتاپی پایتون برای ضبط حرکت موس و کلیدهای صفحه‌کلید (از جمله F1 تا F12 و میانبرهایی مثل Ctrl+C و Alt+Tab) و اجرای دوبارهٔ آن‌هاست.

## اجرا

1. Python 3.10 یا جدیدتر نصب باشد.
2. در پوشهٔ پروژه اجرا کنید:

   ```powershell
   python -m pip install -r requirements.txt
   python .\macro_recorder.py
   ```

3. «شروع ضبط» را بزنید، کارها را در برنامهٔ موردنظر انجام دهید و برای پایان ضبط، پنجرهٔ ماکرو را باز کرده و «توقف» را بزنید.
4. با «ذخیرهٔ ضبط فعلی» یک نام انتخاب کنید. ماکروها در پوشهٔ `macros` کنار برنامه ذخیره می‌شوند.
5. ماکروی ذخیره‌شده را از فهرست انتخاب کنید، سرعت و تعداد دفعات را تنظیم و «اجرا» را بزنید. هنگام اجرا می‌توانید با «توقف» پخش را قطع کنید.

رویدادهای داخل پنجرهٔ خود برنامه ضبط نمی‌شوند. فایل ماکرو یک فایل JSON معمولی است و شامل مختصات موس و کلیدهای واردشده می‌شود؛ ماکروهای حاوی رمز یا اطلاعات حساس ضبط یا با دیگران به‌اشتراک گذاشته نشوند. پخش، ورودی واقعی موس و صفحه‌کلید را به برنامه‌های دیگر می‌فرستد؛ پیش از اجرا، مقصد درست و تعداد دفعات را بررسی کنید.
